Open WebUI now signs users in from their YunoHost session, so the second login is gone.

Check the following before you upgrade:

- SSOwat must be version 12.1.1 or later, otherwise the upgrade stops with an error.
- If the main permission of this app includes `visitors`, remove it. Visitors can no longer sign in.
- Existing accounts are matched by email address. A user whose Open WebUI email differs from their main YunoHost email gets a new, empty account.
- Sign Out now opens the YunoHost portal.
