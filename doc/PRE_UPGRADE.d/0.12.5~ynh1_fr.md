Open WebUI connecte désormais les utilisateurs à partir de leur session YunoHost : la seconde connexion disparaît.

Vérifiez les points suivants avant la mise à niveau :

- SSOwat doit être en version 12.1.1 ou plus récente, sinon la mise à niveau s'arrête avec une erreur.
- Si la permission principale de cette application inclut `visitors`, retirez-la. Les visiteurs ne peuvent plus se connecter.
- Les comptes existants sont associés par adresse e-mail. Un utilisateur dont l'adresse dans Open WebUI diffère de son adresse YunoHost principale obtient un nouveau compte vide.
- Sign Out ouvre désormais le portail YunoHost.
